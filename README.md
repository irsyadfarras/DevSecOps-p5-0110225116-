# DevSecOps Practice - REST API App

## 1. Nama Aplikasi & Fungsi
Aplikasi ini adalah **Flask REST API Sederhana** yang berfungsi menyediakan endpoint pengujian kesehatan sistem (*health check*) dan kalkulasi sederhana, sekaligus diintegrasikan dengan pipeline DevSecOps CI/CD.

## 2. Bahasa & Framework
- **Bahasa Pemrograman:** Python 3.11
- **Framework:** Flask
- **SAST Tool:** Bandit
- **Test Framework:** Unittest
